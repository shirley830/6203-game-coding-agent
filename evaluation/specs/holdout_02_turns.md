# Turn-based collection

Create a browser grid game where each arrow-key press takes exactly one turn. The player must collect three keys before the exit can be used. After a valid player move, an enemy takes one legal orthogonal step toward the player. Walls block both entities. Enemy contact loses; reaching the unlocked exit wins. Ensure a playable map exists and explain controls. Show key and turn counts, freeze actions after win/loss, and provide restart. No remote assets; document one launch command.
